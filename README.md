# Argumentos Variables Java

Con este ejercicio se aplica la optimizacion del codigo cuando se envian multiples parametros en Java

## Características
- Función principal: variosParametros
- Otra función: imprimirNumeros()
- Combinando las 2 funciones, se demuestra que se puede trabajar con diferentes tipos de datos.
  NOTA IMPORTANTE: Cuando se trabaja con esta funcion la regla es: el argumento (no variable) va de primero y los argumentos variables van al final de la cola

## Tecnologías
- Lenguaje: Java
